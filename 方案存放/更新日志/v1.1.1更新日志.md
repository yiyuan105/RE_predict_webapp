# 更新日志

## v1.1.1 — 前端改版与站点 / 数据来源展示升级（2026-11-19）

依据《开发要求 v1.1.1》完成：保留 v1.1.0 的视觉风格与预测链路，把单页扩展为三页站点，新增**站点模型查看**与**数据来源**栏目、对应的只读接口，以及每页一段「网页简述」。预测结果与既有接口契约未改变。

### 一、需求对照

| 需求 | 实现位置 | 说明 |
|------|----------|------|
| 4.1 多页面 + 统一导航 | `base.html`、`content.py`、`style.css` | 顶部导航：品牌 + 预测 / 站点模型 / 数据来源；当前页高亮 + `aria-current`；窄屏换行 |
| 4.2 网页简述 | `RE_predict_webapp/content.py` | `PAGES` 集中定义三个页面的 `title` / `brief` / `nav_label` / `template`，`page_context()` 注入模板 |
| 4.3 站点模型查看 | `/stations/`、`services/catalog.py`、`services/features.py` | 12 个站点的编码、名称、经纬度、生态/植被、土壤/气候分区、模型状态与特征清单；检索 + 4 个筛选 + 展开详情 |
| 4.4 数据来源栏目 | `/sources/`、`services/sources.py` | 六类来源：名称、类型、路径或地址、用途、更新方式、说明、对应维修手册小节 |
| 4.5 只读接口 | `views.stations_api`、`views.sources_api`、`mysite/urls.py` | `GET /api/stations/`、`GET /api/sources/`，`ok`/`error.code` 风格 |

| 5 单一数据源 | `services/` + `content.py` | 页面、接口、结果区标注同源；前端不读 `models/` 或 `config.json` |

### 二、实现要点

**服务层（新增，视图只做编排）**

- `services/features.py`：`FeatureInfo` + `FEATURES`，集中定义 6 个特征的含义、单位、Open-Meteo 变量名与换算；`describe_features()` 按 `config.json` 的 `features` 顺序输出。与 `weather.FEATURE_VARIABLES` 的一致性由测试守护。
- `services/catalog.py`：`StationCatalog` 汇总站点（含 shp 分区标注）、模型文件状态与特征说明，输出 `stations[]` / `features[]` / `summary`。
- `services/sources.py`：`DataSource` + `SourceCatalog`，六类来源集中定义；位置路径全部由 `DataPaths` / `settings` 推导，`_display()` 转成相对 `BASE_DIR` 的 POSIX 路径；同时输出结果区标注用的 `shorts`。
- `services/rf.py`：新增 `ModelStatus`、`status()`、`feature_names`；`status()` 只做存在性、空文件、可读性检查，**不加载模型**。
- `services/predictor.py`：新增 `RePredictor.station_catalog` 惰性属性，与预测共用同一批站点/模型实例，避免二次加载 shp。

**视图与路由**

- 三个页面：`home`（无参数渲染页面，带 `lat/lon` 仍走旧纯文本）、`stations_page`、`sources_page`。
- 两个只读接口：`stations_api` → `get_predictor().station_catalog.to_dict()`；`sources_api` → `build_source_catalog().to_dict()`。
- 统一错误外壳 `_readonly_response()`：业务异常按 `STATUS_BY_CODE` 转状态码；未预期异常记日志并返回 500 `INTERNAL_ERROR`。
- `mysite/urls.py` 追加 `/stations/`、`/sources/`、`/api/stations/`、`/api/sources/`。

**前端**

- `base.html`：导航、页面标题、简述、页脚；`index.html` / `stations.html` / `sources.html` 继承它，公共块只写一份。
- `common.js`：`escapeHtml` / `formatText` / `getJson`（解析 `ok=false`）/ `loadSources()`（单次请求 + 失败可重试）。
- `stations.js`：加载 `/api/stations/`，由数据去重生成筛选下拉，按检索词与生态/气候/土壤/模型状态过滤，卡片内 `<details>` 展示模型文件与特征。
- `sources.js`：按 `category` 分组渲染来源卡片与特征表。
- `app.js`：结果区在原有 6 行之外增加「气象来源」「分区依据」两行，文案取自 `/api/sources/` 的 `weather.label` / `shorts`，与数据来源页同源；标注失败静默降级，不影响预测结果。
- `style.css`：新增导航、筛选栏、站点卡片、来源卡片、特征清单样式，沿用原变量与徽标；`≤560px` 全部单列。
